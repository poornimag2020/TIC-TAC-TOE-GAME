# 🎮 Tic Tac Toe Game Using Python

## 📌 Project Overview

Tic Tac Toe is a simple two-player game developed using **Python**. The game is played on a **3×3 board** where two players take turns marking **X** and **O**. The first player to get three marks in a row, column, or diagonal wins the game.

This project demonstrates basic Python programming concepts through an interactive console-based game.

## ✨ Features

- 👥 Two-player gameplay
- 🎯 Interactive 3×3 game board
- ❌ Player 1 uses X
- ⭕ Player 2 uses O
- 🏆 Automatic winner detection
- ⚠️ Invalid position validation
- 🤝 Draw detection
- 💻 Simple console-based interface

## 🎯 How to Play

1. Player 1 starts with **X**.
2. Player 2 plays with **O**.
3. Enter a position between 1 and 9.
4. Players take turns selecting available positions.
5. The first player to complete three consecutive marks wins.
6. If all positions are filled without a winner, the game ends in a draw.
